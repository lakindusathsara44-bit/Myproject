# Myproject

A React + Vite digital portfolio / project space.

## Stack

- React 19
- Vite 7
- Framer Motion
- Lucide React
- GitHub Actions + GitHub Pages

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## GitHub Pages

The Vite base path is configured for this repository: `/Myproject/`.

The workflow at `.github/workflows/deploy.yml` builds the site and deploys the `dist` folder to GitHub Pages whenever a commit is pushed to `main`.

In the repository settings, set **Pages → Build and deployment → Source → GitHub Actions**.
